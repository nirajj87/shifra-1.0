# Shifra 1.0

![Shifra AI](https://devsupport.co.in/tools/images/shifra.png)
 
*A Smart AI Assistant Built with React, Vite, and Google Gemini API*

## 🚀 About Shifra
Shifra 1.0 is an intelligent AI-powered assistant designed to answer your questions, provide insights, and enhance user experience with seamless interactions. Built using **React (Vite)**, **Google Gemini AI API**, and **JavaScript**, Shifra ensures fast, responsive, and dynamic conversations.

## ✨ Features
- 🤖 **AI-Powered Conversations** – Ask anything, and Shifra responds accurately.
- ⚡ **Fast Performance** – Developed using Vite for optimized speed.
- 🔍 **Google Gemini API Integration** – Leverages advanced AI for intelligent responses.
- 🎨 **Beautiful UI** – Built with React for a smooth and interactive interface.
- 🌐 **Web-Based Assistant** – Accessible on any modern web browser.

## 🛠️ Tech Stack
- **Frontend:** React (Vite)
- **AI Engine:** Google Gemini API
- **Programming Language:** JavaScript

## 🔧 Installation & Setup
Follow these steps to run Shifra AI on your local machine:

### 1️⃣ Clone the Repository
```sh
git clone https://github.com/yourusername/shifra.git
cd shifra
```

### 2️⃣ Install Dependencies
```sh
npm install
```

### 3️⃣ Start Development Server
```sh
npm run dev
```

### 4️⃣ Build for Production
```sh
npm run build
```

## 🚀 Deployment Guide
To deploy Shifra AI on a live server:
1. Run `npm run build` to generate the `dist/` folder.
2. Upload the `dist/` folder to your server.
3. Configure your `.htaccess` file (if needed) to serve the app correctly.
4. Ensure Google Gemini API keys are set up.
